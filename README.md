# Samman — Thoughtful Gifting. Meaningful Livelihoods.

> A social-impact corporate gifting platform connecting rural women artisans and food producers with enterprise gifting for Diwali, employee appreciation, milestones, and client appreciation.

---

## 🌸 Overview

**Samman** (*सम्मान* — Honour / Respect) is built on a clear principle: **Not charity. Exchange.** 

Rural women produce foods, recipes, and pantry traditions rooted in the heritage of rural India. Samman provides the channel to carry these handcrafted artisanal products into corporate boardrooms and employee homes at scale.

### Key Highlights
- **Signature Hamper (₹999)**: Curated artisanal set featuring single-origin spices, traditional pickles/preserves, heritage grains/millets, and cold-pressed seed oils.
- **Enterprise Capabilities**:
  - **Custom Co-Branding**: Bespoke outer box sleeves featuring corporate logos and leadership greeting cards (orders 50+).
  - **Pan-India Multi-Drop Logistics**: Bulk HQ drop or direct doorstep courier delivery to remote employees across tier-1, 2, and 3 cities.
  - **Statutory Compliance**: Full GST invoices, MSME alignment, and formal vendor onboarding.
  - **Auditable Social Impact**: Livelihood impact certificates provided with corporate orders.
- **Interactive Lead Capture**: 
  - Dynamic quotation workflow with automated Reference ID generation (e.g. `SAMMAN-Q8492`).
  - Instant 1-click **Send via WhatsApp** and **Open in Email** dispatch.
  - Local browser persistence for demonstration reviews.

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography**: Cormorant Garamond (Display / Serif) + Outfit (UI / Sans)
- **Routing**: Lightweight hash-based client routing with scroll restoration and dynamic SEO meta tags

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Sparkyyy45/samman.git
cd samman
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
The output will be generated in the `dist/` directory, ready for deployment to Vercel, Netlify, or Cloudflare Pages.
